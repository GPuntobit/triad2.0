# --- Limiti strutturali dell'arena (misurati) --------------------------
# source.max_bytes: buffer sorgente (os_read); oltre -> "seed: read error"
# heap.max_bytes:   heap bump senza free (nessuna riciclicita'); i primi
#                   8 byte della fascia heap sono il bump pointer
# list.max_items:   elementi per lista (blocco fisso da 64 slot)
# function.max_params: record funzione da 64 B, 16 B per parametro

# function.max_records: record funzione (128 B ciascuno); oltre -> errore
# file.max_bytes:   byte massimi letti da `readfile`; oltre -> errore

# --- Divergenze dal comportamento di SPEC-CORE.md, misurate ------------
# classe: silent = risultato sbagliato senza errore (chiede guardia
#         statica dedicata); noisy = exit 1 (chiede il veto della
#         guardia statica).
# Una divergenza sparisce da questo elenco quando il seed la risolve:
# in quel caso la regola corrispondente si disattiva da sola.
#
# Risolte e rimosse da questo elenco (misurate il 2026-11-08):
#   D6  — `-=` e `*=` (assegnazione composta a nome) sono implementati;
#   D9  — la chiamata in posizione finale e' valutata;
#   D13 — l'indicizzazione `xs[i]` (1-based) e la scrittura `xs[i] = v`
#         sono implementate (fuori range -> exit 1);
#   D16 — i primitivi §8 `readfile`, `strlen`, `strbyte`, `strsub` sono
#         implementati (vedi [available]); `exit(n)` era gia' dichiarato
#         disponibile ma mancava davvero: ora esiste (codice a 8 bit).
#
# Risolta e rimossa il 2026-11-09:
#   D22 — le parole chiave sono riconosciute come token *esatti* (confine
#         bilatero: `iffy`, `myif`, `endx`, `elsewhere` non sono keyword)
#         e il testo di un letterale non conta per l'annidamento dei
#         blocchi: il seed salta il letterale quando scandisce la fine di
#         un blocco. La guardia statica G-D22 e' stata rimossa.
#
# Correzioni senza id (divergenze *non dichiarate*, cioe' bug):
#   - i simboli non sono piu' stringhe: un oggetto simbolo ha tipo 5 (non
#     1), quindi `strlen(:x)` fallisce come sul riferimento JS e la
#     concatenazione `"a" * :b` fallisce invece di produrre "ab";
#   - `string(:x)` copia i byte del simbolo in una Stringa (come il
#     riferimento JS), invece di restituire il simbolo stesso.
#
# Divergenze aggiunte il 2026-11-08:
#   D24 (noisy)  — l'assegnazione composta a indice `xs[i] += v` non e'
#                  implementata: exit 1 (la forma `xs[i] = v` funziona).
#   D25 (noisy)  — gli interi sono rappresentati con il tag nel bit basso:
#                  il range utile e' [-2^61, 2^61-1], non 64 bit signed come
#                  in SPEC-CORE.md §5. Il seed **rifiuta** (exit 1) un
#                  letterale o un risultato aritmetico fuori range, invece
#                  di produrre un numero sbagliato in silenzio.
#                  Decisione: docs/adr/0003-range-interi-del-seed.md
#                  (il 64 bit resta un vincolo per S1, che gira sul seed).
