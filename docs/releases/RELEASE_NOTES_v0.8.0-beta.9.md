# Triad 2.0 — v0.8.0-beta.9 (2026-11-07)

**Native Linux seed, Node-free toolchain, desktop launcher.**
Full change list in [CHANGELOG.md](../../CHANGELOG.md). Highlights below.

## What's changed

### Added
- **Native Linux seed** — `seed-linux-x86_64`: a static ELF interpreter (no libc, no Wine)
  of the whole Triad-Core language, with **byte-exact parity** against the Windows PE
  (conformance 39/39 — 38/39 with the known `liste` gap — probes 39/39, S1 golden identical).
- **Node-free toolchain** — `install.sh` (pure-`sh` hex decoder, anti-drift check of the
  decoded binary, byte-exact smoke test that fails the install on mismatch), `bin/triad`
  (always execs the seed) and the POSIX CLI `bin/triad-cli` (`run` / `test` / `status`).
- **Node-free verification harness** — `conformance/run.sh`, `tests/probes/run_probes.sh`,
  `verify.sh` (single entry point) and `seed/linux-x86_64/check_seed.sh`.
- **Desktop launcher** — `bin/triad-desktop`: a POSIX session that keeps output and failures
  visible until `:quit` or EOF; `install.sh --desktop` also registers the `.triad` / `.td`
  MIME types, so a double-click opens the file in Triad.
- **S1 front end** — `selfhost/source.td`: a new scanner + root-scan + recursive-descent
  algorithm derived from the machine-code seed; prints the AST in pre-order (byte-identical
  on the PE seed and on the JS reference interpreter).
- **Site generated by Triad** — `tools/site-gen/`: the pages of `docs/` are emitted by Triad
  programs, verified byte-for-byte against the JS reference interpreter.
- **Book: *Fondamenta*** — `docs/FONDAMENTA.it.md` (programming from zero) plus ~900 exercises
  added to the concluded chapters; PDF at 424 pages, KDP-compliant geometry.
- **Repository governance** — `GLOSSARY.md`, ADR `0001` (immutability of the PE dump) and
  `0002` (parity verification without re-running the PE), local issue tracker in `.scratch/`.

### Changed
- **CI on native Linux only** (decision 04): the Windows legs were removed; the PE side is
  still guaranteed by the `seed.hex` hash gate and the frozen goldens (ADR 0002).
- **CI restored** — `ci.yml` contained an unquoted scalar with `": "`, so GitHub could not
  start any job (it only reported "this run likely failed because of a workflow file issue").
  Fixed, plus a new regression test (`tests/security/workflows_yaml.test.py`) asserting that
  every workflow file is valid YAML.
- **Conformance gate with explicit known gaps** — `conformance/gate.sh` runs the oracle
  `conformance/run.sh` and tolerates **only** the already documented failures (`liste`, gap
  N03), always printing them; any other failure fails the gate. `verify.sh` and
  `triad-cli test conformance` use the gate; the pure oracle is still reachable with
  `triad-cli test conformance --strict`.
- **Probe and S1 goldens versioned** — `tests/probes/*.expected.out` and
  `selfhost/*.expected.out` were excluded by git, so a clean checkout failed 23 of the 39
  probes with "golden mancante". They are now versioned, like the `conformance/` goldens.

### Fixed
- **Seed: the broken `xs[i]` codegen is gone** — the November attempt read the list type
  field into the register holding the list pointer (`mov rdx, [rdx]`): reading failed with a
  parse error and writing (`xs[i] = v`) ended in a **SIGSEGV**. The codegen is back to the
  documented state (gap N03 stays open: 1-based `xs[i]` is not implemented in the seed) and
  the PE/ELF dumps match the CI hash gates again (PE `4235a707…`, ELF `0e121db8…`). The
  committed PE binary is unchanged (`631f401f…`).
- **Seed generator** — single entry point `gen_seed.js <windows|linux|all>`: shared codegen
  core + `backend_pe` / `backend_elf`; the `os_*` boundary isolates the system calls.
  The regenerated PE dump stays byte-identical.
- **JS reference interpreter** — `seed/dev/triad_core.cjs` realigned with the seed
  (`get(xs, i)` 0-based, raw newlines inside string literals, ternary with attached `:`).

### Security
- **Credential-storage hardening** — the live GitHub PAT that was sitting in the working tree
  is gone and the token is no longer embedded in the `origin` URL; the push tooling uses a
  throwaway `credential.helper` fed from the environment. New regression test
  `tests/security/no_live_tokens.test.py`.

## Known issues

- The `liste` conformance case still fails on the seed (**38/39** green): the historical gap
  is recorded by the harness (exit 1, empty stdout) and the gate `conformance/gate.sh`
  excludes it explicitly and loudly. Probes are **39/39**. No golden was rewritten to hide
  the gap.
- The Windows GUI launcher (`TriadDesktop.exe`) is **not** shipped in this release: it still
  targets the pre-beta.9 Node CLI (`status` / `test`), which the POSIX `bin/triad-cli` has
  replaced. It must be ported and rebuilt on Windows (`cli/windows-gui/build.ps1`).
