**Body:**
```markdown
🎉 **Triad 2.0 v0.8.0-beta.9** is out (2026-11-07)!

> Triad 2.0 is a programming language that bootstraps itself: the compiler is
> written in Triad and compiled by its own previous version — no host language
> required (S0→S4 bootstrap).

This is the release that makes Triad feel like a *native* language on Linux:
the seed is a static ELF interpreter (no libc, no Wine), byte-exact with the
Windows PE, and the whole toolchain — installer, launcher, CLI, test harness —
runs **without Node.js**.

### 🐧 Native Linux
- `seed-linux-x86_64`: static ELF (8.3 KB, no libc) running the whole Triad-Core
  language — byte-exact parity with the Windows PE (probes 39/39, conformance 38/39,
  the `liste` gap is historical and documented).
- `./install.sh` → `bin/triad` → `triad program.td`: no Node, no runtime, no Wine.
- POSIX CLI `bin/triad-cli` (`run` / `test` / `status`) and a Node-free verification
  harness (`verify.sh`, `conformance/run.sh`, `tests/probes/run_probes.sh`).

### 🖥️ Desktop
- `bin/triad-desktop` keeps output and failures visible until `:quit` or EOF.
- `.triad` / `.td` are registered as MIME types: double-click opens the file in Triad.

### 🧪 New in the tree
- S1 front end (`selfhost/source.td`) derived from the machine-code seed.
- The documentation site is generated by Triad programs themselves (`tools/site-gen/`).
- *Fondamenta*, a book for absolute beginners, plus ~900 exercises; PDF 424 pages, KDP-compliant.

### 🔒 Security
- No live GitHub token in the working tree anymore; the push tooling never stores it in the
  remote URL. New regression test: `tests/security/no_live_tokens.test.py`.
```
