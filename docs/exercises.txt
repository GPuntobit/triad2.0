# Triad Core Exercises

## Tool References
- bin/, sh/

## Node.js Requirements
Node.js ≥ 18 for the interpreter/JS runner and compliance testing.
To seed the environment: decode seed.hex with certutil.
Git is used to clone the repository.

loading static HTML from the site.
