Tutorial

The complete usage tutorial is docs/tutorial/TUTORIAL.md, with translations in Italian, Russian, Chinese and Japanese. It is organised in five parts and forty-nine chapters, from the first program to the internals of the repository.

1. Part I, first steps

Chapter 1 explains what Triad is and how it differs from the languages it draws inspiration from. Chapter 2 covers the installation and the two available runtimes, and chapter 3 writes the first program. This part is deliberately short: the goal is to have a program running today, not to know the whole language.

# the first program x = 6 * 7 println(x)

2. Part II, Triad-Core step by step

Chapters 4 to 17 walk through the subset that runs today: vocabulary, values and printing, variables and assignment, operators and expressions, flow control, functions, lambdas, closures and scopes, lists, strings, symbols and conversions, the bootstrap primitives, execution errors, the machine-code seed semantics, idiomatic patterns and guided exercises.

Every chapter ends with a pointer to the conformance case that acts as its normative reference, so each notion can be checked against a golden output instead of being taken on trust.

Exercises

Chapter 17 collects the guided exercises, one group per topic, and asks for a program and its expected output. They are meant to be solved with the conformance runner at hand: write the program, run it, compare the output with the golden file, and then write the case yourself.

3. Part III, Triad-Full

Chapters 18 to 32 present the complete standard: the full vocabulary and types, typed and multiple dispatch functions, structs, the extended flow control with for, ranges, comprehensions and try, logic with facts and rules, deconstruction, errors as data, contracts, budgets, tracks, declared effects, code as data and macros, the Full builtin, the command line and the REPL, and finally the complete examples with their golden output.

This part can be read today, but only the Core material can be executed: the rest of the standard waits for the self-hosted runtime.

4. Part IV, the project code

Chapters 33 to 43 describe the repository itself: the map of the directories, the native Triad seed and the future self-hosted generator, the Linux seed, self-hosting in selfhost/, how to read and write conformance cases, the development CLI, the AI benchmark, the editor and the site, continuous integration and the contribution flow.

5. Part V, the reference

Chapters 44 to 49 are the reference: the EBNF grammar of Triad-Core, a quick tab of the Core and Full subsets, debugging, the glossary, the status with the known limits and the FAQ.

6. How to use it

Follow the chapters in order and run every example: the Core examples are the same programs as the conformance cases. When a chapter says that a feature belongs to Triad-Full, treat it as reading material until the self-hosted runtime lands, and keep writing Core programs in the meantime.

Source: docs/tutorial/TUTORIAL.md (Parts I to V, chapters 1 to 49), docs/tutorial/ (translations).
