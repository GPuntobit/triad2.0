Editor support

The editors/ folder contains the tools that make Triad readable as a language. They are implementation independent: they describe the syntax defined by SPEC.md, not the behaviour of a particular runtime.

1. What is in the folder

  • vscode/ - the extension: the language identifier, the TextMate grammar for source.triad, and the configuration of brackets, comments and indentation.
  • vim/ - the ftdetect and the syntax files for Vim and Neovim.
  • linguist/ - the ready entry for github-linguist, with the instructions to request the recognition on GitHub.

What the grammar covers

The TextMate grammar highlights both extensions, the line comment and the block comment, the shebang, the escaped strings and the interpolation, the logical variables, the symbols, the macros, the keywords with the options of solve, the builtin types and the type names, the calls and the definitions, the operators, the :- of a rule and the indentation on end. The language configuration takes care of the brackets, the comments and the indentation of the blocks.

2. VS Code

The extension is a plain folder: it declares the language triad with the two extensions and the grammar source.triad. Package it with the official tool and install the result, or copy the folder into the extensions directory of your profile and restart the editor.

cd editors/vscode npx @vscode/vsce package code --install-extension triad-0.2.0.vsix # or copy the folder into the extensions directory cp -r editors/vscode ~/.vscode/extensions/triad

If another extension claims the .td extension, because it is also used by LLVM TableGen, choose Triad explicitly for the new files, or keep using the canonical .triad extension.

The support is syntax only: no extension runs the language, it only describes it. That is why the same files are read the same way in every editor, and why a change to the standard is a change to the grammars.

3. Vim and Neovim

The filetype detection sets the triad filetype for both extensions; the syntax file highlights the keywords, the types, the operators and the comments of the language.

mkdir -p ~/.vim cp -r editors/vim/syntax editors/vim/ftdetect ~/.vim/ # Neovim cp -r editors/vim/* ~/.config/nvim/

4. Recognition as a language

On GitHub the external step is a pull request to github-linguist/linguist. The prepared entry in editors/linguist/languages.yml declares the type, the colour, the canonical extension and the grammar scope; the pull request also needs real samples and the unique identifier that Linguist assigns. The canonical extension is .triad, while .td stays accepted as a historical alias: it is also the extension of LLVM TableGen, so a new file should use .triad.
