Language tour

Triad has two profiles. Triad-Core is the subset the machine code seed runs today; Triad-Full is the complete standard. Every example below says which profile it belongs to, so you always know what can be executed now.

1. Blocks, values and functions

Triad-Core has block syntax, functions in two forms, lexical scope, closures and recursion. The value of a block is the value of its last expression, and conditions are Bool: there is no truthiness and no implicit conversion. The arithmetic is on 64 bit integers with wrapped arithmetic, and the remainder keeps the sign of the dividend.

function area(base, height) base * height end square(x) = x * x fib(n) = n < 2 ? n : fib(n - 1) + fib(n - 2) let n = 10 println(fib(n)) end

Core values

The Core types are Int, Bool, String, Symbol, List, Function and Nothing. There is no float literal: a float of the full language is represented with Core values by the self-hosted implementation. Lists are mutable and their indexes start at 1, symbols are written :name, and the conversions Int, string and Symbol are part of the language.

2. Declared types and multiple dispatch

Triad-Full adds declared types and multiple dispatch: a generic function is a set of methods, and the most specific applicable method wins. Operators extend like ordinary functions, and functions are first class values.

area(n::Number) = :number area(n::Int) = :int area(p::Point) = :point function +(a::Point, b::Point) Point(a.x + b.x, a.y + b.y) end

3. Logic inside the language

Triad-Full. Facts, rules, unification with occurs-check, backtracking and solve are language features, not a library. A goal on a knowledge base predicate is already a query, and the engine is iterative, so a runaway resolution ends with a budget error instead of a stack overflow. They are not in Triad-Core: the seed has no Prolog, the logic engine arrives with the self-hosted implementation (S1).

fact parent(:tom, :bob) rule ancestor(?a, ?d) :- parent(?a, ?d) rule ancestor(?a, ?d) :- parent(?a, ?x), ancestor(?x, ?d) sols = solve ancestor(:tom, ?d) limit 10 depth 50

4. Code as data

Triad-Full. Quote returns code, a macro receives code and returns code. Expansion is pure and it is not hygienic, so gensym is used for temporary names. The tree of the program is uniform, which is what makes this possible. Quote and macros are not in Triad-Core: they arrive with the self-hosted implementation (S1).

macro swap(a, b) t = gensym(:tmp) quote $t = $a $a = $b $b = $t end end

5. Errors, contracts, budgets, traces and effects

These are part of the language and not of a library. The list marks the Triad-Full features: Triad-Core has no error value, no macro and no quote, and an execution error simply ends the program with the exit code 1.

  • Err is a value with a kind, a message and data; try makes the error the value of the expression (Full).
  • requires and ensures declare pre and post conditions, checked at runtime (Full).
  • with budget(steps = 10_000) bounds the body and yields Err(:budget) when it is exhausted (Full).
  • with trace returns the trace as a value, not as printed output (Full).
  • Effects are declared in the signature: !io, !state (Full).
