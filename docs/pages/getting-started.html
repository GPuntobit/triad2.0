Get started

Triad 2.0 is a standalone language with a normative specification, an executable conformance suite and no dependency on other languages. This page takes you from an empty folder to a running program.

1. Requirements

There is no package to install and no compiler to set up: cloning the repository is enough to start. You need Linux x86-64 with the native Triad seed for the reference interpreter, the conformance runner and the development CLI, and Git to fetch the project. That is the whole list on purpose, because a language that wants to be independent from other languages cannot ask for a toolchain before it can run.

# clone the project git clone https://github.com/GPuntobit/triad2.0.git cd triad2.0 # Linux, macOS or WSL: decode the seed and install the launchers curl -fsSL https://raw.githubusercontent.com/GPuntobit/triad2.0/main/install.sh | sh export PATH=$HOME/.local/bin:$PATH

The install script decodes the Linux seed from its hexadecimal dump, checks that it runs and installs the launchers in the local binary directory (~/.local/bin); it prints the export PATH line to add. On Windows nothing has to be decoded to begin with: the launcher falls back to the Node.js interpreter, and the seed can be materialised later with a system decoder.

2. Run a file

The launcher finds a runtime for you: the machine code seed when it is usable, no foreign-language fallback otherwise. Both run the same Triad-Core programs; the differences between them are listed in chapter 15 of the tutorial.

triad examples/benvenuto.triad # launcher bin/triad.cmd examples/benvenuto.triad # Windows wrapper ./bin/triad hello.triad # native machine-code seed ./bin/triad examples/benvenuto.triad

The hyphen in place of the file name tells the interpreter to read the program from the standard input. The arguments of the script are available in ARGS, a list of strings, and a file can start with a shebang line so that it is executed directly.

3. Your first program

A Triad program is a text file that the runtime reads, parses and executes. It prints with println, and the value of a block is the value of its last expression.

function area(base, height) base * height end square(x) = x * x println(area(7, 6)) println(square(4))

The program prints 42 and 16. On Windows the seed is materialised from its own hexadecimal dump, so the language runs without any guest runtime:

certutil -decodehex seed/windows-x86_64/seed.hex seed/windows-x86_64/seed.exe seed/windows-x86_64/seed.exe conformance/core/cases/ricorsione/program.td

The examples folder

The examples/ folder holds ready programs: benvenuto.triad is the welcome program that runs today, while famiglia.td, garanzie.td, macro.td and tour.td show the Triad-Full features. The native interpreter runs the same interpreter in the browser, so a program can be tried without installing anything.

4. The development CLI and the conformance suite

The CLI wraps the development tasks and the conformance runner checks an implementation against the golden cases. The REPL belongs to Triad-Full: the Core profile defines script execution only, and section 10 of SPEC-CORE.md says so explicitly.

sh conformance/run.sh # 37 Core cases sh conformance/run.sh --cases conformance/cases # 12 Full cases bin/triad-cli status bin/triad-cli help
