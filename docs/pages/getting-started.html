Get started

Triad 2.0 is a standalone language with a normative specification, an executable conformance suite and no dependency on other languages. This page takes you from an empty folder to a running program.

1. Requirements

Triad runs through a native x86-64 machine-code seed. The supported Linux setup needs Git, a POSIX shell, and standard command-line utilities; no JavaScript interpreter, Node.js, npm, or browser runtime is required. On other architectures the native seed may not be available.

git clone https://github.com/GPuntobit/triad2.0.git cd triad2.0 ./install.sh --no-desktop export PATH="$HOME/.local/bin:$PATH" triad-cli status

The installer decodes the committed Linux ELF seed, checks the exact golden output, and installs shell launchers in ~/.local/bin. On Windows x86-64, use the Windows native seed and the bin/triad.cmd launcher; the project does not fall back to another language runtime.

2. Run a file

Provide a .triad or .td source file to the native runtime. The currently supported S1 logic subset is selected with --logic.

triad tests/probes/test_simple.td triad-cli run tests/probes/test_simple.td ./bin/triad --logic cognitive/native/s1_discovery.triad

Triad's native seed runs files rather than accepting arbitrary programs from standard input. Check S1 syntax and limits before using logic rules.

3. Your first program

A Triad program is a text file that the runtime reads, parses and executes. It prints with println, and the value of a block is the value of its last expression.

function area(base, height) base * height end square(x) = x * x println(area(7, 6)) println(square(4))

The program prints 42 and 16. On Windows the seed is materialised from its own hexadecimal dump, so the language runs without any guest runtime:

certutil -decodehex seed/windows-x86_64/seed.hex seed/windows-x86_64/seed.exe seed/windows-x86_64/seed.exe conformance/core/cases/ricorsione/program.td

The examples folder

The examples/ folder holds ready programs: benvenuto.triad is the welcome program that runs today, while famiglia.td, garanzie.td, macro.td and tour.td show the Triad-Full features. The website is static: it does not execute Triad code in the browser. Use the native runtime installed locally.

4. Native CLI and conformance tests

The shell CLI provides native run, status and test commands. The Core and S1 conformance suites compare executable output against golden files. Unsupported advanced development commands are not silently routed through a different language.

triad-cli status triad-cli test all sh verify.sh sh cognitive/native/tests/run.sh sh cognitive/native/tests/run_05.sh sh cognitive/native/tests/run_06.sh sh scripts/no-js.sh
