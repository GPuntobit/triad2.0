Playground

Write a Triad program and press Run: the Triad-Core interpreter runs inside the browser and prints its output right below the editor.

This page is generated by a Triad program (tools/site-gen/site_playground.td).

Ready 




How to use


    

  • Type your program in the editor: the panel starts with the Welcome example.
    • 

  • Press Run to execute it, or use Ctrl+Enter (Cmd+Enter on macOS) from inside the editor.
    • 

  • Pick another program from the Examples menu to load it into the editor.
    • 

  • Stdout and stderr land in the output panel. When the program fails, the panel turns red and shows the error message.
    • 



The code runs on a Triad-Core interpreter compiled to JavaScript. Nothing is sent to a server: the program never leaves the page.


Example programs


Functions, short form and recursion


sum(a, b) = a + b
square(x) = x * x
println(sum(2, 3))
println(square(4))

factorial(n) = n < 2 ? 1 : n * factorial(n - 1)
fib(n) = n < 2 ? n : fib(n - 1) + fib(n - 2)
println(factorial(5))
println(fib(10))


Lambdas and closures


double = x -> x * 2
apply = f -> f(3)
println(double(5))
println(apply(x -> x * x))

function add(n)
  x -> x + n
end
f = add(10)
println(f(5))


Lists and push!


lst = []
lst = push!(lst, 10)
lst = push!(lst, 20)
println(lst)
println(length(lst))


Control flow


x = 0
while x < 3
  println(x)
  x += 1
end

if x == 3
  println("three")
elseif x > 3
  println("more")
else
  println("minus")
end


Strings and symbols


s = "Triad"
println(strlen(s))
println(strsub(s, 1, 3))
println(strbyte(s, 1))

p = :alice
println(p)
println(typeof(:sym))

The runtime bundle


The interpreter that runs in the browser is a generated artifact: it is built from seed/dev/triad_core.cjs and must never be edited by hand.


node scripts/docs/build-triad-core.mjs
node scripts/docs/sync-playground-core.mjs


The first command rebuilds the browser bundle, the second copies it to docs/pages/triad-core.js, the file this page loads. Run both before publishing the site to GitHub Pages.
