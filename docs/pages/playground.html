Native execution

Triad runs through the native machine-code seed. An interactive browser interpreter is not provided because the project does not ship JavaScript.

This page is generated by a Triad program (tools/site-gen/site_playground.td).

Run Triad natively

git clone https://github.com/GPuntobit/triad2.0.git
cd triad2.0
./install.sh
printf 'println(42)\n' > hello.triad
./bin/triad hello.triad

Linux x86-64 is currently supported by the native seed. No browser runtime is bundled.

Example programs

Functions, short form and recursion

sum(a, b) = a + b
square(x) = x * x
println(sum(2, 3))
println(square(4))

factorial(n) = n < 2 ? 1 : n * factorial(n - 1)
fib(n) = n < 2 ? n : fib(n - 1) + fib(n - 2)
println(factorial(5))
println(fib(10))

Lambdas and closures

double = x -> x * 2
apply = f -> f(3)
println(double(5))
println(apply(x -> x * x))

function add(n)
  x -> x + n
end
f = add(10)
println(f(5))

Lists and push!

lst = []
lst = push!(lst, 10)
lst = push!(lst, 20)
println(lst)
println(length(lst))

Control flow

x = 0
while x < 3
  println(x)
  x += 1
end

if x == 3
  println("three")
elseif x > 3
  println("more")
else
  println("minus")
end

Strings and symbols

s = "Triad"
println(strlen(s))
println(strsub(s, 1, 3))
println(strbyte(s, 1))

p = :alice
println(p)
println(typeof(:sym))
println(Int("42"))
