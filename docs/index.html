A language in itself, defined by its standard

Triad is a self-contained programming language: block syntax and declared types, multiple dispatch, integrated logic programming (fact, rule, solve), code as data. Errors, contracts, budgets, tracks and effects are part of the language, not a library.

Why Triad

An implementation-independent policy specification, an executable compliance suite, a bootstrapping path to self-hosting.

📜

Normative specification

SPEC.md (0.2.0): vocabulary, grammar, types, semantics, execution, errors, contracts, effects, logic, CLI. §1–§14 and §16 regulations.

✅

Executable conformance

Golden cases with expected stdout and exit code. Any implementation (seed in machine code, Triad-Core, native compiler) must pass them.

🧬

Standalone bootstrap

Seed S0 in machine code (PE Windows + ELF Linux). Roadmap S1–S4 towards Triad without guest languages. See BOOTSTRAP.md.

🧠

Integrated logic

fact, rule, unification with occurs-check, backtracking, solve with ?x logic variables. Like in Prolog, but in the language.

🪞

Code as given

Uniform tree Node, quote :( … ) with $, macro. Native introspection and metaprogramming.

🛡️

Contracts and effects

requires/ensures, budget (with budget), traces (with trace), declared effects (!io, !state). Errors as data (Err).

Triad-Core in action

A program and the output it actually produces, run by the same interpreter that executes the conformance suite.

# functions, block form, recursion function area(base, height) base * height end square(x) = x * x fib(n) = n < 2 ? n : fib(n - 1) + fib(n - 2) println(area(7, 6)) println(square(4)) println(fib(10))
# output 42 16 55

Quick Start

Install with the official script (native seed) or run programs in the browser playground — no install needed.

# Linux / macOS / Termux curl -fsSL https://raw.githubusercontent.com/GPuntobit/triad2.0/main/install.sh | sh export PATH="$PWD/bin:$PATH" # run a file triad examples/benvenuto.triad # run the Core conformance suite (37 cases) node conformance/run.mjs # REPL bin/triad-cli help
